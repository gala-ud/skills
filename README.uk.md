# skills

Навички для AI-агентів соло-розробника: від ідеї до релізу.

Невеликі [Agent Skills](https://agentskills.io), які можна комбінувати. Вони
змушують агента працювати так, як працює уважна команда з однієї людини:
записати специфікацію, спланувати до коду і перевірити власну роботу, перш ніж
назвати її готовою.

Працює з Claude Code, Codex, Cursor, Gemini CLI та іншими агентами, що читають
`SKILL.md`.

[English](README.md)

## Встановлення

Усі навички:

```bash
npx skills add gala-ud/skills
```

Одна навичка:

```bash
npx skills add gala-ud/skills --skill plan-first
```

Або скопіюйте теку зі `skills/` у теку навичок вашого агента, наприклад
`.claude/skills/` чи `.agents/skills/`.

## Навички

| Етап | Навичка | Що робить |
|---|---|---|
| Ідея | [`idea-to-spec`](skills/idea-to-spec/SKILL.md) | Перетворює сиру ідею на односторінкову специфікацію з чіткими межами, зокрема з переліком того, чого у версії 1 не буде. |
| План | [`plan-first`](skills/plan-first/SKILL.md) | Пише план із 3–8 кроків до будь-якого коду. Кожен крок має перевірку і лишає проєкт робочим. |
| Рев'ю | [`self-review`](skills/self-review/SKILL.md) | Переглядає власний дифф очима скептичного рецензента перед комітом. Кожне твердження потребує команди та її результату. |

Далі будуть інші етапи: схема даних, налагодження, тести, реліз, передача стану.

## Принципи

- **Одна навичка — одна задача.** Кожна коротша за 100 рядків.
- **Працює поруч з іншими наборами.** Жодних глобальних правил поведінки і
  загальних назв, тож можна ставити разом із великими колекціями.
- **Портативність.** Лише стандартний frontmatter `SKILL.md` і звичайний
  Markdown. Без скриптів і мережевих викликів.
- **Докази замість упевненості.** Агент показує, що запускав і що вийшло.
